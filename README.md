# wyn — wynuser

Маркетплейс юзернеймов: Usernames, Numbers, Proxy, Gifts, Gaming, Other.
Каждый тред проходит ручную модерацию: продавец загружает скрин-доказательство владения,
ты проверяешь его в админке и одобряешь, отклоняешь или банишь.

## Что внутри

```
wynuser/
├─ public/
│  ├─ index.html        ← сайт (Browse, Members, сообщения, профили, New Thread)
│  ├─ logo.png, favicon.png ← логотип
│  └─ admin.html        ← админ-панель (/admin)
├─ netlify/functions/
│  ├─ listings.mjs      ← API сайта: список одобренных тредов + создание нового
│  ├─ auth.mjs          ← аккаунты: регистрация, вход, профиль (аватар, био), смена пароля
│  ├─ users.mjs         ← поиск людей по юзернейму и публичные профили
│  ├─ avatar.mjs        ← отдаёт аватарки
│  ├─ messages.mjs      ← личные сообщения на сайте
│  └─ admin.mjs         ← API админки: одобрить / отклонить / удалить / бан / разбан / пользователи
├─ netlify/lib/util.mjs ← общий код (пароли, сессии, баны)
├─ netlify.toml
└─ package.json
```

Данные хранятся в **Netlify Blobs** (встроено в Netlify, бесплатно, база данных не нужна):
`listings` — треды, `proofs` — скрины, `bans` — баны, `users` — аккаунты, `sessions` — входы, `avatars` — аватарки, `dm` + `inbox` — переписки.

## Аккаунты

- Любой может зарегистрироваться: логин (3–20 символов) + пароль (от 8 символов). Почта не нужна.
- Пароли хранятся как хэш (scrypt), в открытом виде их не видит никто, даже ты.
- Создать тред можно только с аккаунтом. В админке у каждого треда виден аккаунт автора.
- Не больше 3 регистраций с одного IP в сутки.
- Имена admin, moderator, support, wyn, wynnet, wynuser и т.п. заняты, чтобы никто не выдавал себя за админа
  (список `RESERVED` в `netlify/functions/auth.mjs`).

## Как запустить на Netlify с админкой (10 минут, без терминала)

> Не перетаскивай папку в Netlify Drop: так загрузятся только страницы, а сервер
> (аккаунты, треды, сообщения, админка) не заработает. Нужен путь через GitHub.

**1. Загрузи проект на GitHub**
1. Зайди на github.com → **New repository** → название, например `wynuser` → **Create repository**.
2. На странице репозитория нажми **uploading an existing file**.
3. Открой распакованную папку `wynuser`, выдели всё внутри (`public`, `netlify`, `netlify.toml`,
   `package.json`, `README.md`) и перетащи в окно браузера → **Commit changes**.
   Важно: в корне репозитория должен лежать `netlify.toml`, а не папка `wynuser`.

**2. Подключи к Netlify**
1. app.netlify.com → **Add new site → Import an existing project → GitHub**.
2. Разреши доступ и выбери репозиторий `wynuser`.
3. Ничего не меняй в настройках сборки (их задаёт `netlify.toml`) → **Deploy**.

**3. Задай пароль админки**
1. В Netlify: твой сайт → **Site configuration → Environment variables → Add a variable**.
2. Key: `ADMIN_PASSWORD`, Value: длинный пароль, который знаешь только ты (16+ символов).
3. **Deploys → Trigger deploy → Deploy site**, дождись статуса **Published**.

**4. Готово**
- Сайт: `https://твой-сайт.netlify.app`
- Админка: `https://твой-сайт.netlify.app/admin`

Если что-то не так, админка сама покажет, что именно:
«The server part isn't running» — функции не задеплоились (скорее всего, загружено через Drop
или `netlify.toml` лежит не в корне репозитория); «Set your admin password» — не задан `ADMIN_PASSWORD`.

Дальше любые изменения: загружаешь новые файлы в тот же репозиторий на GitHub,
Netlify пересобирает сайт сам. Данные (аккаунты, треды, переписки) при этом сохраняются.

### Через терминал (если удобнее)
```bash
npm install -g netlify-cli
cd wynuser
npm install
netlify login
netlify init
netlify env:set ADMIN_PASSWORD "твой-длинный-пароль"
netlify deploy --build --prod
```

## Запоминание паролей

- При входе и регистрации браузер предлагает сохранить пароль (Chrome, Edge, Safari, Firefox, телефоны).
- Вход держится 365 дней на устройстве, повторно вводить пароль не нужно.
- Админка тоже запоминает пароль на этом устройстве. Кнопка Sign out его стирает.

## Админка (/admin)

Слева разделы:

- **Overview** — сколько тредов ждут проверки, участники, баны, муты, непрочитанное в поддержке, быстрые действия.
- **Review** — новые треды со скрином-доказательством (клик = полный размер). Approve / Reject / Edit / Delete.
- **Threads** — все треды: Live, Pinned, Rejected, Pending. Можно **закрепить** (Pin) — закреплённые всегда наверху
  маркета и в блоке «Pinned» на главной; **редактировать** что угодно (название, цену, описание, раздел);
  снять с публикации; удалить. Кнопка **Post official thread** — тред от имени wynuser, сразу живой и без доказательства.
- **Members** — все аккаунты. «Manage» открывает карточку участника:
  - **Ban** на 1 час / 24 часа / 7 дней / 30 дней / навсегда, по желанию ещё по IP и устройству. Временный бан снимается сам.
  - **Mute** — запрет писать сообщения, выкладывать треды или и то и другое, на время или навсегда. Человек видит причину.
    В поддержку замученный писать может (чтобы мог обжаловать).
  - **Warn** — предупреждение, приходит ему сообщением от поддержки; счётчик предупреждений.
  - **Значок** рядом с ником: Verified, Trusted seller, Staff, VIP или любой свой текст.
  - Изменить био, убрать аватарку.
  - **Reset password** — новый пароль показывается тебе, передаёшь его человеку.
  - **Log out everywhere** — выкинуть со всех устройств.
  - **Read chats** — прочитать любые переписки и удалить отдельные сообщения.
  - Удалить аккаунт (вместе с тредами или без).
- **Support** — переписка с участниками от имени «wynuser support».
- **Bans** — все активные баны, разбан, быстрый бан по нику.
- **Settings** — текст плашки Notice наверху сайта; выключатели регистрации, новых тредов и сообщений
  (например, на время техработ); **сообщение всем участникам** сразу.
- **Log** — журнал всех твоих действий в админке.

## Что поменять потом

В `public/index.html` блок `CATS` — категории, подкатегории, подписи полей.
Когда расскажешь, как выставлять Numbers, Proxy и Gifts, — поля для них добавляются там же
и в `netlify/functions/listings.mjs` (тот же список `CATS`).

## Режим предпросмотра

Если открыть `index.html` без бэкенда (просто файлом), появляется плашка Preview: регистрация и треды
сохраняются только в этом браузере. На Netlify с функциями всё идёт через сервер.

## Сообщения и поддержка

- Ссылок на Telegram на сайте больше нет: покупатель жмёт **Message** на треде или в профиле и пишет продавцу прямо на сайте.
- Людей можно найти по юзернейму: **Members** в шапке, блок «Find a member» справа или поиск в окне сообщений.
- Кнопка **Support** / **Message support** открывает чат с «wynuser support». Ты отвечаешь из админки, вкладка **Support**.
- В админке, вкладка **Users** → **Chats**: можно прочитать переписки любого участника (только чтение), если на него пожаловались.
- Чат обновляется раз в 4 секунды, счётчик непрочитанных в шапке — раз в 25 секунд.

## Правила юзернеймов

В разделах Usernames и Proxy (все платформы) юзернейм должен начинаться с буквы, быть не короче 4 символов
и состоять только из английских букв, цифр и `_`. Ник аккаунта тоже должен начинаться с буквы. Проверяется и на сайте, и на сервере
(`USERNAME_ITEM_RE` в `netlify/functions/listings.mjs`, `ITEM_RE` в `public/index.html`).

## Страницы сайта

- `#/` — главная: разделы маркета списком, свежие треды, справа профиль и последняя активность
- `#/market`, `#/c/usernames/telegram` — маркет: фильтры слева, треды таблицей или карточками (переключатель List / Grid)
- `#/t/<id>` — тред: большая «табличка» с юзернеймом, цена, кнопка Message seller, карточка продавца
- `#/u/<username>` — профиль: аватар, био, статус, дата регистрации, треды участника
- `#/members` — поиск участников, `#/rules` — правила
- Поиск по всему сайту: кнопка в шапке или клавиша `/`
